# 035：相似资料是否诱导模型补充答案的四组对照

日期：2026-11-19。

## 结论

**观察到了相似资料诱导额外检查建议的信号，但没有证明历史上那句完整的“规则/靶值掩盖失控”只能由S3造成。直接删S3不能作为已验证修复。**

保留S3的A/C各有2/5添加了质控规则或设置检查，引用却仍挂在不含这一检查的S1/S2上；不含S3的B/D没有这种扩展。原具体掩盖机制未完整明确重现，A4最接近，已单列相似语义风险，不能因缺少“掩盖”原词而声称问题消失。

这表明故障更接近“生成对相近证据的选择、概括和引用约束不稳定”，不能笼统说LLM不理解室内/室间区别。Context有足够正确证据，也有可能诱导扩写的背景；增加这段背景并非必然出错，C5还正确限定“若发现失控信号”后才引用S3说明后续步骤。

## 冻结与执行

- 复用已冻结的035实际问题与Context，AI bundle `g000033-71ec3c52f3`。
- 模型实际返回均为`gpt-5.6-sol`，提示固定`minimal_four`，temperature=0，输出预算1000。
- 每组5次，全新20次生成；另作20次现有Gold裁判评价。没有复用历史答案充当重复；0个执行错误，没有因答案质量重抽。
- 只增删证据块；保留正文、来源标题、顺序、S编号。A请求与历史候选原始请求逐字段相同。不同组不重编号，防止把编号变化当内容效应。
- Gold只进入事后裁判。默认配置、运行代码、正式提示、Gold、索引、源资料均未修改。受保护文件运行前后哈希通过。
- 这是生成器隔离诊断，不是端到端验收。没有重跑召回/BGE或采用选段新策略。

“规则/设置检查扩展”是运行后发现的探索性指标，不是把预设的具体掩盖机制指标偷偷改宽。原具体机制未完整明确复现；A4的近似表述单独保留。复核由Codex对照实际引用完成，不是业务人员逐题人工审核，未覆盖自动原判。

### 具体多答

- A3：增加“再查……室内质控设置与执行情况”，引S1/S2。来源可支持复核质控状态，没有给出设置检查细节。
- A4：增加“确认并非质控规则或质控状态判断不当，排除实际质控失控”，引S1/S2。最接近历史问题，未明确说规则/靶值如何掩盖失控，仍作为同类风险，不能称其完全正确。
- C1：增加“质控规则是否存在异常”，引S2；S2没有规则说明。
- C2：增加“复核……规则应用，确认不存在未识别的失控”，引S1/S2；所引正文没有规则应用内容。

这四次同时满足“背景S3在输入中”“规则相关检查被补入”“答案未引用承载规则文字的S3”。因此有理由优先怀疑生成受S3影响后又把引用挂回主证据，但小样本不能证明模型内部生成路径，不能认定历史那句必然从S3搬来。

### 其他发现

- C1、C4给出“前述均无异常，再考虑样本本身质量问题”。S1/S2是并列原因清单，没有规定这种条件门槛。一般建议排查顺序可由回答组织，但“只有前面正常才考虑后面”增加了约束，须单列。
- B2没有明确表达室内质控不能覆盖分析前/后这一Gold解释项；它确实列出了样本和结果处理检查，不能夸大为这些实际检查全部漏掉。自动F3缺失原判保留。
- D5漏掉三类主要原因中的“质控失控”。D仍有S1/S2这条原文，说明删除S3后也会发生生成漏答，不能归因于删了必需证据。
- 自动裁判将A/C全部判一致，却没有标出上述规则检查与条件顺序细节。原判不改，来源复核另存。总一致率不是本轮主要结论。
- C5引用S3讲失控后的处理，但明确前提“若发现失控信号”，体现了背景资料可能有用，不能一律视为错误场景删掉。

## 采用与下一步

本轮不采用“按035删S3”，不采用“只留两段”，也不据此恢复固定词条件过滤。可以采纳的是诊断认识：**正确证据已在时，模型仍可能从相似背景补出具体检查，并把主证据引用贴到补充内容上；更少Context不保证必答完整。**

下一轮最小验证应只改变生成对证据使用的通用要求，保留这四组Context作为回归，另覆盖其他业务里“并列原因被编成条件顺序”和“背景说明被当作当前处理”的问题。若仍需改选段，必须证明通用策略可减少这类扩写且保住跨文件必要事实，不能从单题S3位置写删段规则。

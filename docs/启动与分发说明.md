# 本地全文搜索工具：分发与启动说明

## 分发方式

1. 分发 `本地多格式全文搜索工具` 整个目录，目录内的 EXE 和 `_internal` 必须保持在同一层级。
2. 接收方先将整个目录解压到本机 SSD 的普通目录，再双击 `本地多格式全文搜索工具.exe`。
3. 不要只复制 EXE；不要从压缩包预览、网络共享、网盘同步目录或 U 盘直接运行。
4. 若 ZIP 文件属性中有“解除锁定”，先解除锁定后再解压运行。
5. 收到目录后，可用同目录 `SHA256SUMS.txt` 核对文件完整性。

## 启动提示与诊断

- 程序会在 Python 入口后立即记录启动阶段。超过 15 秒仍未显示窗口时，会显示当前阶段和诊断日志位置。
- 启动失败时会显示原生错误提示。请将日志 `%LOCALAPPDATA%\LocalFullTextSearch\logs\startup.log` 提供给支持人员。
- 若该日志不存在，说明程序可能在 Python 入口前被 Defender、企业 EDR、SmartScreen、DLL 加载或权限策略阻止。请检查 Windows 安全中心“保护历史记录”、企业安全软件日志和事件查看器。
- 首次使用没有旧索引数据库时，正常本机 SSD 环境不应出现数分钟无窗口等待；优先检查完整目录是否被拆分、是否在网络/同步目录运行，以及安全软件是否正在扫描。

## 索引模式

- `更新全部` 使用普通配置。
- `性能模式更新` 只在用户点击一次后执行本次索引。程序会探测 CPU、可用内存和索引盘类型，为本次任务选择并发与内存预算；完成、取消或重启后自动恢复普通配置。
- 程序不会根据空闲时间、定时器、开机事件、键鼠活动或文件变化自动启动性能模式索引。
- ZIP 内的可解析成员会作为独立来源调度；目录文件与 ZIP 成员只有在完整 SHA-256 一致、解析器版本一致时才复用解析结果。

## 支持信息

反馈启动或索引问题时，请一并提供：应用完整目录的版本、`SHA256SUMS.txt` 校验结果、`startup.log`、失败文件列表，以及问题文件所在盘符是本地 SSD、机械盘、网络盘还是可移动盘。

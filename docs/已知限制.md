# 已知限制

- OCR 准确率受图片清晰度、倾斜、手写和模型影响，不能保证百分之百准确。
- PaddleOCR 未安装时，图片和扫描 PDF OCR 会记录为依赖缺失。
- 加密 PDF 没有密码时无法提取正文。
- Word 页码无法通过 python-docx 准确获得，第一版只显示段落、表格、页眉页脚位置。
- 老版 DOC/XLS/PPT 第一版记录为暂不支持。
- Office 文本框、SmartArt、嵌入对象不保证完整提取。
- Office COM 精确定位、PDF 页内坐标高亮和搜索结果导出仍是后续增强。
- 文件变化监控代码已预留，默认关闭；启动时重新扫描仍是最可靠的补偿方式。
- 正则表达式搜索尚未在 UI 中开放。
- 当前 UI 的索引任务采用单后台 worker 串行写库，后续可扩展为解析队列和独立数据库写入队列。

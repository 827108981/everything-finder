# 四项精简提示：固定输入回归

## 任务和边界

用户批准从两轮提示实验中保留四项要求作为精简候选，保持原提示其余证据边界和拒答协议，再做固定输入回归。只更改生成system提示的显式选项，不改变默认提示、持久化设置、QueryPlan、召回、BGE窗口最高分、简单选段、Context、Gold或裁判。

采用的是通用提示要求，不按题号、文件或报警码切换提示。历史实验结果保留，不覆盖。

## 候选全文

原提示保持原有内容，仅将“如果证据无法回答问题”改为“如果所有所问内容均无可用证据”，拒答仍须只输出“资料中没有足够依据。”。该条件调整是为避免原来的整题拒答要求与新增的部分回答要求矛盾，不是更改应用拒答协议。

原提示末尾增加：

```text
部分问题有依据时，先回答有依据的部分，并说明其余部分的证据限制。
操作流程须保留必要前提、顺序和结束动作；只回答本题需要的步骤。
参数须对应正确对象、单位和条件；资料同时给出标称值与正常范围时，分别说明。
结论及适用范围须由实际引用支持；多来源共同支持的结论引用必要来源，不同型号或版本的差异分别说明，不取并集。
```

显式选项名：`minimal_four`。默认仍为`baseline`，历史`behavior/completeness/combined/unified`结果及选项保留。

## 运行前冻结的协议

- 当前AI bundle：`g000033-71ec3c52f3`，实际索引包核实，不使用全文索引generation替代。
- 111个既有问题：50 reviewed、60 pending、1 disputed；各方案首次分别统计。
- 7个重点问题每方案总共3次：014、016、020、021、035、电压、条码；共250个生成及独立判分任务。
- 两组均重新生成，不把上一批原提示结果当本批基线；相同模型、预算、温度、实际Context和用户输入。
- 每任务包含生成和独立裁判请求，不等于250个HTTP调用。
- 7题真实AnswerService入口每方案一次，共14次；实际Context必须与冻结输入相同。
- 所有任务完成后，只对执行错误做一次低并发恢复；回答差、引用错或业务错不择优重试。
- 019按用户要求保持冻结，但仍保留在固定集合分母。
- 不增加少样本示例或新的业务词典，不改变Gold状态，不将正确答案注入生成请求。
- 只验证现有固定集合的回归，不宣称这111题是全新的独立泛化验收集。
- 停止条件：完成预定任务、真实入口、判分争议复核、原资料绑定检查和HTML交付；不边跑边调整提示。
- 采用门槛：来源支持的回答收益、已有正确项回归保护、真实入口及拒答协议兼容。存在新确认的实质错误时不整体采用，不能只看总一致数。

冻结文件和实际提示见`reports/rag_minimal_four_prompt_20261119/protocol.json`。

- 250/250个生成加独立判分任务完成，0个执行错误，0次恢复重跑；实际模型均为`gpt-5.6-sol`，finish reason均为stop。所有250条的Context哈希一致，生成请求中未包含Gold。
- 正式reviewed集合固定50题：原提示41/50一致，四项候选44/50一致。自动逐题变化为6升、3降，净增3；不可把这当作独立泛化结果。pending 60题为53/60与53/60；disputed 1题两组均1/1。
- 正式自动增益为rag-biz-045、rag-row-holdout2-001、rag-biz-015、rag-biz-034、rag-biz-016、rag-biz-020。034两组的业务结论都拒绝仅凭单一HBsAg结果作诊断/治疗决定，主要差别是裁判把回答归入answer还是refuse，按判分争议观察，不计为确定的提示业务收益。
- 正式自动退步为rag-biz-039、rag-biz-035、evidence-flow-independent-07。035精简版首轮提出“质控规则/靶值设置掩盖失控”，引文S1/S2不支持；后两轮及真实入口回答没有该句，说明输出有波动，但该未支持主张已出现。039核心回答两组均正确，精简版另外解释主、副波长功能，但引用S5只说副波长特征，不能支持主波长主张。密封圈题两组都正确回答66,000次和编码；裁判仅因精简版没有补“到寿命需更换”判其不完整，而本题只问寿命和编码，属于Gold/裁判口径疑点，原分保留、另行记录。
- 七个重点问题均三次固定输入复测。016精简版3/3一致，真实入口一致；020隔离生成3/3一致，但真实AnswerService候选生成引用不存在的[S37]，被引用校验拦截，没有返回答案。021精简版1/3一致、2/3错误，真实入口也错误，无法稳定保留条件分支。035精简版2/3一致、1/3错误，真实入口一致。电压题两组都3/3不完整；精简版没有补Context中已有的22.8–25.2V正常范围。条码题候选3/3一致，引用两个不同资料来源；对照组3/3被判错误，主要是来源范围证据不足，不是码制内容检索不到。014两组主要都是需澄清；候选一轮被裁判为一致，但没有稳定改善。

### 结论

**暂不采用四项提示作为默认提示。**44/50对41/50是有价值的候选信号，尤其部分答案覆盖和条码跨来源引用；但它仍带来来源不支持的额外断言，并在直接法反推Medica的pending样例上暴露条件推理错误。重点流程题021不稳定，参数题未覆盖已知范围，020真实入口无效引用被拦截。没有达到“来源支持的收益且无新增实质错误”的采用门槛。

默认仍为原提示。建议下一轮先将四项拆成独立因子或小组合，至少先验证“部分回答”和“限制无依据扩展/引用范围”两个维度；每一项都须保留拒答格式和请求内容不变，并用另一批未调提示的问题作验收。不要先把候选设为默认，也不要修改Gold来适应本轮输出。

# 安装程序与管理员权限说明

## 为什么安装时需要管理员权限

安装程序会注册一个按需使用的 Windows 后台服务，用于读取本机 NTFS 变化记录。这样应用重启后可以直接定位新增、修改和删除的文件，减少对数万文件目录的重复扫描。

该服务的权限范围是固定的：

- 只读取指定本地磁盘的 NTFS 变化记录和文件元数据；
- 不读取文件正文，不修改或删除用户文件；
- 不监听网络端口，主程序通过本机命名管道通信；
- 不接受任意命令，只接受检查点和变化记录查询。

Windows 的 UAC 确认发生在安装阶段，用于注册服务。主程序快捷方式不设置为“始终以管理员身份运行”，日常打开应用不需要管理员权限。

## 安装后行为

安装程序会：

1. 将主程序安装到 `Program Files`；
2. 注册“本地全文搜索 - NTFS 变更监控服务”；
3. 将服务设置为自动启动；服务空闲时只等待本机请求，不主动扫描；
4. 创建开始菜单快捷方式，并按用户选择创建桌面快捷方式。

安装程序完成后不会自动启动主程序。请先关闭 Setup，再从桌面或开始菜单快捷方式手工启动，避免安装器或 Windows Restart Manager 的退出流程影响正在启动的索引任务。

主程序优先调用该服务。如果服务不可用、磁盘不是 NTFS、变化日志断档或检查点不可信，程序自动回退到普通目录扫描，不影响索引正确性。

卸载时会停止并删除该服务。升级或卸载服务可能再次触发一次 UAC，这是 Windows 修改系统服务的正常要求。

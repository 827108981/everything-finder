## 字段说明

| 字段 | 含义 |
| --- | --- |
| `id` / `group_id` | 题目唯一编号 / 同一业务问题的不同问法所共用的组名。当前各题来自不同业务问题。 |
| `question` | 拟真的用户问法，不额外补充隐含条件。 |
| `corpus_snapshot` | 标注适用的 AI 索引包 `bundle_id`；本批为 `g000008-9f01fc283b`。 |
| `expected_behavior` | `answer`=有直接证据，完整回答；`partial_answer`=只回答有依据的部分；`clarify`=先询问决定答案的缺失条件；`refuse`=资料不足，不能给出所要求的具体结论。 |
| `constraints` | `scope`=单/多/全部项目，`stage`=样本检测/定标/质控等，`direction`=偏低/偏高/异常，`object`=所问对象。用户未明确的条件用空字符串；机型在问题或证据中体现，不擅自推断项目范围。 |
| `gold_evidence` | 一个来源片段就是一条证据；连续的操作流程可作为同一片段，不表示每一步都是独立证据。内含文件相对路径、页码、位置、原文与相关性；2=直接支持，1=相关但不足，0=不相关。答案步骤写在 `required_facts` 中。跨产线拒答题没有正面证据，留空数组。 |
| `hard_negatives` | 容易误召回的相似片段，附不应采用的原因。 |
| `required_facts` / `forbidden_claims` | 合格回答必须包含的事实 / 不得作出的错误或无依据结论。 |
| `missing_fields` | 澄清题需要补充的字段；例如第 014 题需确认磁分离盘标识。 |
| `review_status` | `pending`=待审核，`reviewed`=人工核实通过，`disputed`=有争议。 |
